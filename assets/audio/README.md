# Batik Parabos — Audio Assets

Place the following `.mp3` files in this directory to activate the contextual soundscape
on the homepage "Five Stages, One Garment" section:

| Filename              | Stage | Description                                    |
|-----------------------|-------|------------------------------------------------|
| `fabric-rustle.mp3`   | 01    | Soft textile / fabric rustling                 |
| `canting-wax.mp3`     | 02–03 | Canting tool + wax workshop ambience           |
| `dye-water.mp3`       | 04    | Soft water / liquid / dye bath ambience        |
| `atelier-ambient.mp3` | 04    | Cinematic ambient music / emotional rise       |
| `atelier-finish.mp3`  | 05    | Subtle atelier resolution / gentle room tone   |

## Guidelines

- Keep files **short and loopable** (10–30 seconds).
- Use gentle fade-in/fade-out at the file boundaries for seamless looping.
- Keep overall loudness **low** — the JS manager applies further volume reduction.
- Format: MP3, 128–192 kbps, mono or stereo.
